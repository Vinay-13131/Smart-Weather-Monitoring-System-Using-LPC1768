# Smart Weather Monitoring and Environmental Data Acquisition System Using LPC1768

## Project Overview
An embedded systems project developed using the LPC1768 ARM Cortex-M3 microcontroller for environmental monitoring, threshold-based alerts, and automated control.

## Features
- Environmental parameter monitoring using sensors.
- LCD-based display of sensor readings and system status.
- Keypad-based parameter selection.
- Threshold comparison for abnormal conditions.
- LED and buzzer alerts.
- Relay-based automatic fan control.
- Internal flash memory for data storage.

## Hardware and Software
- **Microcontroller:** LPC1768
- **Programming Language:** Embedded C
- **Display:** 16×2 LCD
- **Inputs:** Environmental sensors and keypad
- **Outputs:** LEDs, buzzer, relay, and fan
- **Development Environment:** Keil µVision

## Repository Contents
- `lockedversion_ex.c` — Main project source code.
- `project.h` — Project header file.

## Project Objective
To develop a microcontroller-based environmental monitoring system that displays sensor information and activates alerts or control outputs when configured thresholds are exceeded.
